# Taller: Formularios Reactivos con Validaciones — Angular 17

Formulario de registro de usuario construido con **Reactive Forms** en Angular 17,
utilizando arquitectura modular tradicional (NgModule, sin componentes Standalone).

## Tecnologías

- Angular 17
- TypeScript
- SCSS
- ReactiveFormsModule

## Instalación

1. Clonar el repositorio:

\`\`\`bash
git clone https://github.com/Juanes-URBA/Reactive-forms.git
cd Reactive-forms
\`\`\`

2. Instalar las dependencias:

\`\`\`bash
npm install
\`\`\`

## Ejecución del proyecto

\`\`\`bash
ng serve
\`\`\`

Luego abrir en el navegador:

\`\`\`
http://localhost:4200
\`\`\`


## Notas

- No se consume ninguna API externa.
- No hay backend ni persistencia de datos.
- Toda la lógica de validación reside en TypeScript, no en la plantilla.
